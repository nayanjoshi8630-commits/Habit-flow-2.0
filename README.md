# Habit Flow 2.0

A beautiful habit tracking mobile app built with React + TypeScript + Vite, compiled to Android APK with Gradle.

## Features
- 📊 Track daily habits
- 🎯 Set reminders
- 📈 View statistics
- 🎮 Gamification with coins
- 🔒 PIN lock security
- ✨ Confetti animations

## Build Status
✅ All components integrated and fixed
✅ Ready for APK build

## Getting Started
```bash
npm install
npm run build
```
